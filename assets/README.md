# Shared Assets & Services (LDT Toolbox Contributions)

This folder records descriptions and pointers to the **reusable assets, services, and governance templates** produced by the **NeWG+** pilot for contribution to the **LDT4SSC Assets and Services Repository** and the **EU LDT Toolbox Marketplace** (per Section 4.2 of the Pilot Application Form and Annex 5/6 of the Pilot Grant Agreement).

---

## Planned Reusable Outputs

### 1. Madrid Flagship (*Market-to-City*) Reusable Package

| Asset / Service | Openness / Licence | Target Phase | Description |
|---|---|---|---|
| **NeWG Mercamadrid Onboarding-by-Service Guide** | Open Documentation (`CC BY 4.0`) | WP2 / WP5 | Methodology and integration guide for onboarding low-digital-maturity wholesalers and SMEs into data spaces via operational bridge apps without standalone connector complexity. |
| **MIRA / Data-Space Governance Templates** | Open Documentation (`CC BY 4.0`) | PD4 (M6) / WP5 | Reusable ODRL/ABAC policy templates, qualified discoverability rules, anti-competition visibility clauses, EUDI/VC delegation patterns, and retention/export schedules. |
| **Smart-Mesh Logistics Context Service Specs** | Open Specification (`CC BY 4.0` / `Apache-2.0`) | PD3 (M3) / WP3 | API specifications and selective-ingestion curation rules (Green IT) for H3 cell demand, route feasibility, corridor risk, learned segment costs, DUM curb/loading friction, and emissions. |
| **Mercamadrid (MCP) Flow Statistics Service** | Governed Shared Service | WP3 / WP4 | Aggregated, privacy-preserving flow statistics for market infrastructure managers and municipal mobility/commerce planners. |
| **Route, ETA & Exception Shared Service** | Governed Shared Service | WP3 / WP4 | Real-time route feasibility, time-window risk, and cold-chain/DPP exception notifications for Twin-of-Twins / City OS consumption. |
| **Wholesale Market Digital-Utility Business Model Pattern** | Open Documentation (`CC BY 4.0`) | PD5 / WP5 | Replicable business-model blueprint for European wholesale markets (WUWM / MUFPP networks) evolving from passive real-estate landlords to sovereign digital-utility hubs. |

### 2. Codogno (*Territory-to-City*) Agrifood Corridor Twin Package

| Asset / Service | Openness / Licence | Target Phase | Description |
|---|---|---|---|
| **Fresh Corridor Context Service** | Open Spec / Shared Service | WP3 / WP4 | Structured corridor-level telemetry and flow context connecting rural/peri-urban producers with municipal and metropolitan demand nodes. |
| **Producer Dispatch Planning Service** | Open Spec / Shared Service | WP3 / WP4 | Simulation and scheduling support for coordinated producer dispatches and shared cold-chain routes. |
| **Urban Loading & Access Service** | Open Spec / Shared Service | WP3 / WP4 | Modelling and validation of municipal loading/unloading windows, station/intermodality access, and curb regulation in a medium-sized city. |
| **Scenario Pack (Before/After) & Observatory Method** | Open Documentation (`CC BY 4.0`) | WP4 / WP5 | Harmonised comparative simulation pack and lightweight observatory methodology for medium-sized cities and producer territories. |
| **Cross-Scale LDT Interconnection Guide (`WS1`)** | Open Documentation (`CC BY 4.0`) | T4.3 / WP5 | Practical blueprint demonstrating how to interconnect a capital-scale flagship LDT with a lighter medium-city corridor LDT without forcing symmetrical technical stacks. |
